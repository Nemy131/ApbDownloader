# Aplaybox Downloader

Windows 10/11 x64용 한국어 데스크톱 유틸리티입니다. Aplaybox 작가의 **모델·모션 배포 게시물**을 페이지 끝까지 조회하고, 선택한 게시물의 팔로우·좋아요·즐겨찾기 조건을 처리하여 파일을 내려받습니다. 일러스트·기사와 외부 파일 호스팅 서비스는 다운로드 대상에서 제외됩니다.

## 실행

- 프로젝트 폴더에서는 `Start.cmd`를 더블클릭합니다. 배포 EXE를 우선 실행하며 프로젝트의 기존 `data`(로그인·설정·기록)를 그대로 사용합니다. 배포 EXE가 없으면 제공된 `vendor/electron` 런타임으로 소스를 실행합니다.
- 배포 폴더에서는 `dist/AplayboxDownloader/AplayboxDownloader.exe`를 실행합니다. EXE 하나만 옮기지 말고 **폴더 전체**를 유지하세요.
- 처음부터 빌드하려면 PowerShell에서 `./Build.ps1`을 실행합니다. 공식 Electron 45.3.1 Windows x64 ZIP의 고정 SHA-256을 검증한 뒤 패키징합니다. 별도 npm 설치가 필요하지 않습니다.
- Node.js와 npm이 있는 개발 환경에서는 `npm install` 후 `npm start`도 가능합니다.

## 사용 순서

1. 작가 URL을 입력하고 조회 범위를 선택합니다. 기본값은 모델+모션 전체입니다.
2. **목록 불러오기**를 누릅니다. 게시물 목록만 조회하며 상세 조건은 읽지 않습니다. 전체 페이지 수·게시물 수가 맞아야 전체 조회 완료로 표시합니다. 조건은 다운로드를 시작할 때 게시물별로 확인합니다.
   한 번 조회한 작가 목록은 `data/author-lists.json`에 저장됩니다(최근 30개 작가·범위). 같은 작가로 다시 전환하면 사이트를 다시 조회하지 않고 저장된 목록과 진행 상태를 바로 표시하며, 상태 줄에 조회 시각이 나옵니다. 최신 목록이 필요하면 **새로고침**을 누릅니다. 모델+모션 전체 목록이 저장되어 있으면 모델만·모션만 범위도 그 목록에서 바로 표시합니다.
3. **로그인 창**에서 직접 로그인합니다. 이후 **계정 확인**을 누릅니다. 비밀번호는 프로그램에 전달하거나 저장하지 않습니다.
4. 팔로우·좋아요·즐겨찾기 자동 처리 범위를 선택하고 **이 계정 설정 저장**을 누릅니다. 모두 끈 상태로 저장할 수도 있습니다. 설정은 계정별입니다. 허용한 행동은 다운로드 뒤에도 유지됩니다.
5. 저장 폴더와 게시물을 선택합니다. 검색, 상태·조건 필터, 날짜·제목 정렬, 전체·필터 결과 선택을 지원합니다. 조건 필터(다운로드 가능·팔로우·좋아요·즐겨찾기)는 조건을 한 번 확인한 게시물에만 적용됩니다. 목록을 불러온 직후에는 해당 게시물이 표시되지 않습니다.
6. **선택 다운로드**를 누릅니다. 게시물마다 조건 확인 → 허용한 계정 행동 처리 → 사이트 다운로드 인증 → 첨부 목록 확인 → 파일 전송 순서로 진행합니다. 새로 확인된 첨부 파일은 모두 선택된 상태로 받습니다.
7. 첨부 목록이 확인된 게시물은 카드에서 파일을 개별 선택·해제할 수 있으며, **재시도 / 재개** 또는 다시 **선택 다운로드**를 누르면 선택한 파일만 받습니다.
8. CAPTCHA나 비밀번호 창에서 인증하면 다운로드 주소를 확인한 뒤 인증 창·해당 게시물 창·로그인 창을 자동으로 닫고 계속 진행합니다. 별도로 재개 버튼을 누를 필요가 없습니다. 인증을 최대 10분 기다리며, 시간 초과 또는 다른 오류로 대기 상태가 되면 안내를 확인하고 **재시도 / 재개**를 누르세요.

사이트가 광고 대기 시간을 요구하면 해당 창을 표시하고 사이트의 카운트다운이 끝난 다음 진행합니다. CAPTCHA, 배포 비밀번호, 팔로우 기간, 계정 레벨, 포인트·결제, 작가의 권한 제한을 우회하지 않습니다. 포인트 소비, 댓글, 메시지 전송은 자동으로 수행하지 않습니다. 현재 사이트의 즐겨찾기는 별도 폴더 없는 단일 동작입니다. 폴더 선택이 추가되는 등 사이트 구조가 바뀌면 자동 진행을 중단하고 사이트에서 직접 처리해야 합니다.

## 파일·진행 기록

**기존 모델 제외 선택**은 현재 선택에서 저장 폴더에 있는 자료만 선택 해제합니다. **폴더에 없는 모델 선택**은 현재 검색·필터 결과에서 저장 폴더와 하위 폴더에 없는 자료를 모두 선택합니다. 후자의 경우 기존 선택은 이 결과로 바뀝니다. 게시물 ID가 포함된 폴더, 실제 파일이 남아 있는 다운로드 기록, 확인된 Aplaybox 고유 첨부 파일명으로 판정합니다. 여러 첨부 중 일부만 있으면 나머지만 선택합니다. 빈 폴더·0바이트 파일·`.part` 임시 파일은 제외 근거로 사용하지 않습니다. 첨부 이름이 아직 공개되지 않았고 ID 폴더나 기록도 없는 자료는 기존 여부를 확정할 수 없어 선택 상태로 남깁니다. 임의로 바꾼 이름이나 비슷한 모델명은 추측하지 않습니다. 검사 중 취소하거나 읽기 오류가 나면 기존 선택을 유지합니다. 이 기능은 파일 존재 여부 판정이며 모든 로컬 파일의 무결성 검사는 아닙니다.

파일은 `저장 폴더/원본 파일명`으로 바로 저장합니다. 작가명·게시물명 하위 폴더를 생성하지 않습니다. Windows 금지 문자와 예약 이름을 정리하고, 충돌 시 `(1)`, `(2)`를 붙입니다. 이전 버전에서 만든 하위 폴더와 파일은 그대로 유지하며 기존 파일 제외 검사에는 계속 포함됩니다. 긴 경로는 더 짧은 저장 폴더를 선택하도록 안내합니다.

- 임시 `.part`에 내려받은 다음 크기·오류 문서 여부를 검증합니다.
- 서버가 준 파일명을 우선 사용합니다. 실제 파일명·용량이 다운로드 응답에서만 공개되면 그때 확정됩니다.
- 완료 기록에 SHA-256을 저장합니다. 재실행·재시도 시 기존 파일의 크기와 SHA-256이 일치해야 건너뜁니다.
- SHA-256은 로컬 무결성·중복 확인용입니다. 서버의 공식 체크섬과 비교했다고 주장하지 않습니다.
- 중단 파일은 임시 파일을 제거하고 처음부터 다시 받습니다. 현재 버전은 바이트 단위 이어받기를 지원하지 않습니다.
- 만료된 URL은 재시도할 때 사이트의 정상 인증 절차를 다시 거쳐 갱신합니다.
- 내려받은 파일을 자동 실행·압축 해제하지 않습니다.

설정과 기록은 실행 위치의 `data`에 저장됩니다. 소스 실행 시 프로젝트 루트의 `data`, 패키지 실행 시 EXE 옆의 `data`입니다.

| 파일 | 내용 |
| --- | --- |
| `settings.json` | 계정별 자동 처리 범위, 저장 폴더, 동시 다운로드 수 |
| `queue.json` | 게시물·파일 목록과 상태. 다운로드 URL·인증 토큰 제외 |
| `author-lists.json` | 작가별로 한 번 조회한 목록(최근 30개). 작가 전환 시 재조회 없이 사용 |
| `history.json` | 파일 식별자, 완료 경로, 크기, SHA-256 |
| `events.jsonl` | 조건 확인·계정 행동·다운로드 결과 로그 |
| `session.enc` | Windows DPAPI로 암호화한 사이트 쿠키 |

로그인 브라우저 세션은 메모리에서만 운영하고, 쿠키를 Electron safeStorage로 암호화하여 저장합니다. 로그아웃은 창·세션·저장된 쿠키를 정리합니다. 같은 Windows 사용자 권한으로 실행되는 다른 프로그램까지 차단하는 보안 경계는 아닙니다. 배포 시 개인 `data` 폴더를 포함하지 마세요.

## 구현과 유지보수

- `src/core.js`: 페이지 검증, 조건 판정, 상태 재확인, 안전한 파일 저장·무결성 검증
- `src/site.js`: 실제 Aplaybox API 형식, 격리된 사이트 창, 정상 다운로드 인증 흐름
- `src/main.js`: IPC, 계정별 설정, 세션 보호, 작업 대기열·파일 동시 다운로드
- `src/ui/`: 한국어 UI, 검색·선택·진행 표시
- `test/`: 외부 계정을 변경하지 않는 핵심 회귀 테스트
- `research/`: 조사 당시 공개 사이트 자료와 응답 샘플. 실행에는 필요하지 않습니다.

2026-11-12 확인한 공개 클라이언트 빌드는 `1793871316231`입니다. 목록 요청은 `user/getTargetUserWorks`, 상세는 `work/getWorkDetails`이며 실제 요청 형식을 확인했습니다. 다운로드는 사이트의 `downloadAdvertCheck` 흐름을 실행하고 `downloadWorkNewV2`의 정상 응답에서 허용된 URL만 전달받습니다. 직접 호출로 CAPTCHA나 광고 단계를 건너뛰지 않습니다. 사이트가 Vue 구성 요소·응답 형식을 변경하면 `src/site.js`를 갱신해야 합니다.

## 자동 업데이트

배포 EXE를 실행하면 몇 초 뒤 GitHub 저장소의 최신 릴리스를 확인합니다. 현재 버전보다 새 버전이 있으면 "지금 업데이트 / 나중에 / 이 버전 건너뛰기 / 업데이트 로그 보기"를 묻는 창이 뜹니다. **업데이트 로그 보기**는 GitHub 릴리스 페이지(버전별 변경 내역)를 브라우저로 열고 같은 질문을 다시 표시합니다.

업데이트 중에는 화면 위쪽 가운데 패널에 다운로드 진행률(%·용량), 압축 해제, 재시작 단계가 표시되고, 다시 실행된 뒤 완료 또는 실패 결과가 표시됩니다.

- **지금 업데이트**: 릴리스의 `AplayboxDownloader-Windows-x64.zip`을 받아 크기와 SHA-256을 확인한 뒤 앱을 종료하고, 앱 폴더의 파일을 새 버전으로 덮어쓴 다음 다시 실행합니다. `data` 폴더(로그인 정보·기록·북마크·설정)는 건드리지 않습니다. 결과는 `data/update.log`에 남습니다.
- **이 버전 건너뛰기**: 해당 버전은 다시 묻지 않고, 그보다 새 버전이 나오면 다시 묻습니다(`data/update-skip.json`).
- 인터넷 연결이 없거나 GitHub 응답이 실패하면 아무 창도 띄우지 않습니다. 확인 요청에는 버전 조회 외의 정보를 보내지 않습니다.
- 소스 실행(`vendor/electron`)에서는 확인하지 않습니다. 확인 대상 저장소는 `package.json`의 `updateRepo`입니다.
- 앱 폴더에 쓰기 권한이 없는 위치(예: Program Files)에서는 업데이트가 실패할 수 있습니다.

새 버전을 배포할 때는 `package.json`의 `version`을 올리고 빌드한 뒤, `v버전` 태그로 GitHub 릴리스를 만들고 `AplayboxDownloader-Windows-x64.zip`(최상위 폴더 `AplayboxDownloader/`, `data` 제외)을 첨부합니다.

```powershell
node --test test/*.test.js
./vendor/electron/electron.exe . --smoke-test
```

실제 사이트 읽기 검증 결과는 `data/live-verification.json`에 저장됩니다. 이 검증은 로그인·계정 행동·파일 다운로드를 실행하지 않습니다. 실제 다운로드와 실계정 행동의 검증 여부는 `VERIFICATION.md`를 참고하세요.

## 알려진 제한

- 로그인 없이 읽을 수 있는 목록·상세 정보와 로그인 후 조건 처리·파일 다운로드는 서로 다른 검증 범위입니다.
- 첨부 파일명·용량을 인증 전에 제공하지 않는 게시물은 미확인으로 표시합니다. 목록 조회만으로 계정 행동이나 다운로드 인증을 실행하지 않습니다.
- 다운로드 조건·파일 확인은 게시물별 순차 처리하고, 파일 전송은 설정한 1~4개로 병렬 처리합니다. 조건을 중복 처리하거나 취소하는 엔드포인트는 호출하지 않습니다.
- 사이트가 게시물을 추가·삭제하여 페이지 총수가 조회 도중 변하면 전체 완료로 처리하지 않고 재조회하도록 안내합니다.
- CAPTCHA·비밀번호·추가 인증은 사람이 처리해야 하며, 인증 창을 닫았다면 재시도 시 처음부터 진행합니다.
- 외부 링크, 일러스트·기사, 유료 결제·포인트 소비, 다운로드 미제공 자료는 자동 다운로드하지 않습니다.
- 최초 인증 뒤 파일 선택 단계에서 서버가 다운로드 횟수를 집계할 수 있습니다. 사이트에서 다운로드 URL을 발급받는 정상 절차에 따른 것입니다.
- 코드 서명 인증서는 포함하지 않은 포터블 빌드입니다.

## 북마크
각 모델의 ‘☆ 북마크’ 버튼으로 저장하고 북마크 탭에서 다시 선택해 다운로드할 수 있습니다. 작가 목록을 바꾸거나 앱을 재실행해도 data/bookmarks.json에 보관됩니다. 북마크 해제는 파일이나 사이트의 즐겨찾기를 삭제하지 않습니다. 다운로드 시 최신 배포 조건·주소를 다시 확인하므로 로그인·CAPTCHA 또는 배포 종료에 따른 제한은 적용됩니다. 각 탭의 다운로드 버튼은 그 탭에서 선택한 항목만 처리합니다.


### 중국어 간체 자동 번역
상단 또는 내부 탐색 도구의 자동 번역 체크박스로 중국어 간체→한국어 번역을 켜고 끌 수 있습니다. 기본값은 ON이며 변경 즉시 저장됩니다(직접 끄면 그 선택을 유지합니다). ON이면 모델·작가 이름과 화면에 보이는 사이트 텍스트를 Google 번역 서비스에 전송합니다. 입력 영역과 인증 대화상자는 제외하며 저장되는 파일명은 변경하지 않습니다. OFF이면 원문을 복원합니다. 키 없이 사용하는 온라인 번역 연결은 서비스 변경이나 요청 제한으로 중단될 수 있으며, 실패하면 원문을 표시합니다. 이미지 안의 글자는 번역하지 않습니다.

### 작업 현황·플로팅 다운로드 바
하단 영역의 작업 현황 패널은 현재 단계(목록 조회 중, 폴더 검사 중, 조건·첨부 확인 중, 다운로드 중, 사용자 조작 필요, 일부 실패, 완료)와 게시물 상태별 개수(조건 확인·대기·다운로드 중·인증 필요·완료·실패), 파일 완료 수·전송량·속도, 진행 막대를 표시합니다. 개수는 다운로드를 시도한 게시물 기준입니다. 목록을 스크롤해 하단 버튼이 화면 밖에 있으면 오른쪽 아래에 현황과 선택 다운로드·재시도/재개·취소 버튼을 담은 플로팅 바가 표시되고, 하단 영역이 보이면 숨겨집니다. ▾/▴ 버튼으로 상태별 개수를 접을 수 있으며 접힘 상태는 저장됩니다. 작업이 끝나 완료·일부 실패·사용자 조작 필요가 표시되면 **확인** 버튼으로 결과 표시를 닫을 수 있습니다(재실행 후에도 유지, 진행·완료 탭의 기록은 그대로). 이후 상태가 바뀌면 결과가 다시 표시됩니다.

### 화면 테마
Aero는 Frutiger Aero 스타일로, 옅은 하늘색 바탕에 반투명 흰 유리 패널을 두고 짙은 남색 글자를 씁니다. 주요 버튼은 부드러운 파란 그라데이션, Aplaybox 탐색은 민트색이며 제목 앞의 아쿠아·민트 강조 막대와 카드 상태 점(완료 초록·실패 빨강·인증 필요 주황·다운로드 파랑·조건 확인 보라)으로 상태를 구분합니다(`src/ui/theme-aero.css`).

### 테마 선택·글꼴
상단 바의 **테마** 선택기에서 Light(기본값), Dark, Aero 중 하나를 고를 수 있으며 선택은 저장됩니다. Dark는 검은 바탕에 한 단계 밝은 타일을 두고, 영역 제목(작가 목록 주황·작가 페이지 초록·다운로드 설정 파랑·필터 보라), 주요 버튼(파랑), 카드 상태(완료 초록·실패 빨강·인증 필요 노랑·다운로드 파랑·조건 확인 보라)에만 색을 씁니다(`src/ui/theme-dark.css`). Light는 연회색 바탕에 테두리 없는 흰 타일로 상단 설정을 배치하고(작가 페이지 8칸, 작가 목록·다운로드 설정 4칸), 카드와 썸네일은 모두 같은 크기로 맞춥니다. 오른쪽 아래 플로팅 바는 작게 표시합니다. 작업 현황은 파란 그라데이션 강조 타일로, 카드 상태는 색 태그(완료 초록·실패 빨강·인증 필요 노랑·다운로드 파랑·조건 확인 보라)로 표시합니다. 각 테마는 `src/ui/theme-aero.css`, `src/ui/theme-bento.css`이며 전환은 `src/ui/theme.js`가 처리합니다.

UI 글꼴은 나눔스퀘어라운드 Bold이며 `src/ui/fonts/NanumSquareRoundB.ttf`로 앱에 내장되어 있어 글꼴을 따로 설치할 필요가 없습니다(`src/ui/fonts.css`). 저작권은 NAVER Corporation에 있으며 SIL Open Font License 1.1로 배포됩니다. 출처는 `src/ui/fonts/NOTICE-NanumSquareRound.txt`에 있습니다.

배포 자료를 하나 이상 선택하면 왼쪽 아래에 **✕ 선택 해제** 플로팅 버튼(선택 개수 표시)이 나타납니다. 누르면 전체 목록·북마크에서 선택한 게시물을 모두 해제합니다. 작업 중에는 비활성화됩니다.

처음 실행해 배포 자료 목록이 비어 있으면 위쪽 기본 제공 작가 버튼 영역이 강조 테두리와 "시작하기" 안내로 표시됩니다. 목록을 불러오면 강조가 사라집니다.
