사용 방법

작가 목록 불러오기

위쪽 작가 버튼(기본 작가·★ 북마크)을 누르면 그 작가의 배포 자료를 불러옵니다. 다른 작가는 Aplaybox 탐색이나 더 찾아보기 →로 작가 페이지에 들어가 현재 작가 목록 불러오기를 누릅니다.

작가 북마크

목록을 불러온 뒤 ＋ 현재 작가 북마크로 저장합니다. ★ 버튼에 마우스를 올리면 ✕로 삭제, 우클릭하면 이름 변경·삭제 창이 열립니다.

선택과 다운로드

카드를 누르거나 빈 곳에서 드래그해 여러 개를 선택하고, 오른쪽 아래 ⬇로 선택한 자료를 받습니다. 실패한 자료는 ⟳로 다시 시도하고, 진행 중인 작업은 붉은 ✕로 취소합니다. 카드의 ⬇는 그 자료만 바로 받습니다.

3D 미리보기

썸네일에 마우스를 올려 재생 버튼을 누르면 모델 디스플레이가 열립니다. Esc나 ✕로 닫습니다.

목록 보기

필터·검색·정렬로 목록을 좁히고, 네모 아이콘으로 썸네일 크기를 고릅니다. …에서 크기를 세밀하게 조절할 수 있습니다.

번역 · 설정

왼쪽 위 자동 번역을 켜면 중국어 제목·페이지를 한국어로 번역하고, 옆 목록에서 번역 엔진을 고릅니다. 저장 폴더·다운로드 조건 자동 처리·3ds Max 경로는 ⚙ 설정에서 바꿉니다.
