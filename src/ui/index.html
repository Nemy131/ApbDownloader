사용 방법

  • 업로더 불러오기위쪽 북마크 버튼을 누르면 그 업로더의 자료 목록을 불러옵니다.
  • 로그인오른쪽 위 로그인 버튼으로 Aplaybox에 로그인하세요. 다운로드에 필요합니다.
  • 처음 설정오른쪽 위 ⚙에서 저장 폴더를 고르고 이 계정 설정 저장을 누르세요.
  • 선택카드를 누르거나 빈 곳에서 드래그하면 선택됩니다.
  • 다운로드오른쪽 아래 ⬇를 누르면 선택한 자료를 모두 받습니다. 카드의 ⬇는 그 자료만 받습니다.
  • 3ds Max 임포트오른쪽 아래 육면체 아이콘을 누르고 보낼 곳과 변환 옵션을 정하세요.
  • 3D 미리보기썸네일에 마우스를 올려 재생 버튼을 누르세요. Esc로 닫습니다.
  • 검색 · 필터 · 정렬목록 위 돋보기와 필터 버튼을 사용하세요. 화살표 버튼은 업로드 날짜 순서를 뒤집습니다.
  • 번역탭 줄 오른쪽 메뉴에서 엔진을 고르세요. 끄려면 번역 사용 안 함을 고릅니다.
  • 북마크 버튼찾아보기 →에서 업로더를 북마크하세요. 버튼을 우클릭하면 이름 변경·삭제, 끌면 순서가 바뀝니다.
  • 기록 정리다운로드 진행·완료, 임포트 완료 탭의 전체 기록 삭제를 누르세요. 파일은 지워지지 않습니다.
  • 썸네일 크기네모 아이콘 세 개 중에서 고르고, …에서 세부 크기를 조절하세요.
  • 테마번역 메뉴 왼쪽 목록에서 Light · Dark · Aero 중 하나를 고르세요.
