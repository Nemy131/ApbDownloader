MMD 모델 임포터 (PMX > Blender > FBX > 3ds Max 2020)
====================================================

aplaybox 등에서 받은 MMD 모델(.pmx 또는 압축 파일)을 3ds Max 2020 으로 가져옵니다.
압축 해제, FBX 변환, 임포트, 재질 연결까지 한 번에 처리합니다.
본과 스킨은 가져오지 않고 메시, UV, 재질, 텍스처, (선택) 모프만 가져옵니다.


1. 준비물
---------
- 3ds Max 2020
- Blender + Cats Blender Plugin 또는 MMD Tools 애드온
  (Blender 3.6, 4.1, 4.2, 5.0 + Cats 조합에서 동작을 확인했습니다)
- 반디집 (압축 파일을 넣을 때만 필요)

ImportMMD.ms 와 pmx_to_fbx.py 는 반드시 같은 폴더에 두세요.


2. 사용 방법
------------
1) 3ds Max 에서 Scripting > Run Script... 로 ImportMMD.ms 를 실행합니다.
   (파일을 뷰포트에 끌어다 놓아도 됩니다)
2) [추가...] 를 눌러 .pmx / .zip / .rar / .7z 파일을 고릅니다. 여러 개를 한 번에 선택할 수 있습니다.
3) 필요하면 옵션을 바꿉니다. 처음에는 기본값 그대로 써도 됩니다.
4) [임포트 실행] 을 누릅니다.
   처음 실행할 때는 Blender 를 찾고 검증하느라 수십 초가 더 걸립니다.
5) 끝나면 파일별 성공/실패 요약이 표시됩니다.

모델마다 레이어가 하나씩 만들어지고, 여러 모델은 X축으로 나란히 배치됩니다.


3. 주요 옵션
------------
모프(표정) 유지       켜면 표정 모프가 Morpher 모디파이어로 들어옵니다.
원본 이름 복원        오브젝트, 재질, 모프 이름을 원래의 중국어/일본어 이름으로 되돌립니다.
                      끄면 영문(ASCII) 이름을 씁니다.
메시                  하나로 합치기 / 재질별 분리
재질                  Standard / Physical Material
알파가 있는 텍스처    컷아웃 / 반투명 Opacity / 사용 안 함
스케일                MMD 1단위를 몇 cm 로 볼지. 기본 8 (표준 MMD 크기)
파일명 코드페이지     압축을 풀었을 때 파일명이 깨지면 바꿔 보세요.
                      중국 모델은 GBK, 일본 모델은 Shift-JIS 가 보통입니다.
암호                  암호가 걸린 압축 파일용. 저장되지 않으므로 매번 입력합니다.

Blender 와 반디집 경로는 자동으로 찾습니다. 못 찾으면 "직접 지정" 으로 바꾸고
[찾아보기...] 로 blender.exe / bz.exe 를 골라 주세요.

후처리 버튼 [Edit Poly: Quadrify All + 보더 버텍스 Weld (0.001)]
    씬에서 선택한 오브젝트마다 스택 맨 위에 Edit Poly 를 올리고
    Quadrify All > 보더 전체 선택 > 버텍스 선택으로 변환 > Weld (Threshold 0.001) 를 실행합니다.
    MMD 모델은 같은 위치의 버텍스가 여러 개로 갈라져 있는 경우가 많은데, 이 버튼으로 다시 붙일 수 있습니다.
    되돌리려면 추가된 Edit Poly 모디파이어를 지우면 됩니다.
    모프(Morpher)가 있는 오브젝트에도 쓸 수 있습니다. Edit Poly 는 Morpher 위에 올라갑니다.


4. 만들어지는 파일
------------------
<압축 파일과 같은 이름의 폴더>     압축 해제 결과 (다음에는 다시 풀지 않고 재사용)
<pmx 가 있는 폴더>\_max_fbx\       변환된 FBX, 이름 대응표(.json), 로그
ImportMMD.ini                      경로와 옵션 설정
ImportMMD_log.txt                  마지막 실행 로그

원본 압축 파일은 건드리지 않습니다.
텍스처는 압축을 푼 폴더의 것을 그대로 참조하므로, 그 폴더를 지우거나 옮기면 텍스처 연결이 끊어집니다.


5. 문제 해결
------------
"mmd_tools 를 쓸 수 있는 Blender 를 찾지 못해..."
    Blender 에 Cats 또는 MMD Tools 애드온이 설치, 활성화되어 있는지 확인하세요.
    결과 창에 Blender 별 탈락 이유가 표시됩니다.
    포터블 Blender 는 "추가 검색 폴더" 에 경로를 넣거나 "직접 지정" 을 쓰세요.

텍스처가 안 붙거나 압축 해제 폴더의 파일명이 깨져 있음
    코드페이지를 바꾸고 "이미 해제된 폴더가 있어도 다시 해제" 를 켠 뒤 다시 실행하세요.

"암호가 필요한 압축 파일" / "압축 암호가 틀림"
    암호 칸에 암호를 입력하고 다시 실행하세요. 암호는 보통 배포 페이지에 적혀 있습니다.

"압축 파일 안에 .pmx 가 없음"
    .pmd 등 다른 형식의 모델은 지원하지 않습니다.

뷰포트에서 뒤에 있는 부분이 앞에 그려짐
    Max 뷰포트는 투명 재질을 오브젝트 단위로만 정렬하기 때문에, 알파를 쓰는 재질끼리
    겹치는 각도에서 생길 수 있습니다. 렌더링 결과에는 영향이 없습니다.
    거슬리면 "알파가 있는 텍스처" 를 "사용 안 함" 으로 바꿔 다시 임포트하세요.

모프가 일부만 들어옴
    Morpher 모디파이어는 채널이 100개까지입니다. 모프가 그보다 많은 모델은 확인되지 않았습니다.

옵션을 바꿨는데 반영이 안 됨
    이미 임포트된 모델은 바뀌지 않습니다. 씬에서 지우고 다시 임포트하세요.

그 밖의 오류는 ImportMMD_log.txt 와 _max_fbx 폴더의 .log 파일을 확인하세요.


6. 참고
-------
- 모델마다 이용 약관(재배포, 개변, 상업적 이용 조건)이 다릅니다. 압축 파일 안의 ReadMe 를 확인하세요.
- .rar 파일은 지원하도록 만들었지만 실제 파일로 시험하지는 못했습니다.
