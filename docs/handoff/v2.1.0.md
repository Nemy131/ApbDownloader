# v2.1.0 인수인계

작성일: 2026-11-14 · 이전 버전: v2.0.0

## 이번 버전 변경 사항
- **화면 압축** (`src/ui/index.html`, `src/ui/ui.js`, `src/ui/readability.css`): 배너 문구 제거, 앱 아이콘(`#brand`, 호버 시 버전 툴팁)·북마크 버튼·계정을 한 줄(`#topRow`)로. 탭 줄 오른쪽에 테마 선택·번역 메뉴. 선택·필터·썸네일 버튼을 한 줄로. 검색은 돋보기 토글(`#searchToggle`), 정렬은 화살표 토글(`#sortToggle`, 신작부터/초기작부터). 하단 UI 제거, 우하단 플로팅 독(다운로드·Max 임포트·재시도·취소).
- **용어**: 작가 → 업로더, 작가 버튼 → 북마크 버튼.
- **북마크 버튼 통합** (`main.js`의 `shortcutAuthors`, 설정 `authorOrder`·`hiddenAuthors`): 기본 제공 업로더와 사용자가 추가한 업로더가 같은 버튼. 우클릭 이름 변경·삭제, 포인터 드래그로 순서 변경(`beginAuthorDrag`, FLIP 애니메이션).
- **내장 데이터** (`src/builtin/`, `tools/build-builtin.cjs`): 기본 업로더 목록과 번역(제목) 결과를 앱에 포함.
- **다운로드 파이프라인** (`src/core.js`의 `pipeline`, `main.js`): 조건 확인과 다운로드를 병렬 단계로 분리. 설정 `concurrency`(기본 6)·`concurrencyUnlimited`·`checkConcurrency`(기본 3). 팔로우·좋아요·즐겨찾기 자동 처리 기본 ON.
- **탭**: 전체 목록 / 다운로드 진행 / 다운로드 완료 / 임포트 완료 / 북마크. 탭별 기록 삭제·전체 기록 삭제, "임포트하지 않은 모델 선택". 필터는 "완료된 모델 제외".
- **3ds Max 임포트** (`src/maxbridge.js`, `src/max/ImportMMD.ms`, `src/max/pmx_to_fbx.py`): 테마에 맞춘 임포트 창(`#maxImportDialog`)에서 PMX 임포터 옵션 설정(`OPTION_DEFS`), 다운로드 중에도 완료된 자료 임포트 가능, 임포트 결과 기록(`data/max-imports.json`). Blender 변환 병렬화(`ImportMMDTask`·`pumpConverts`)와 FBX 재사용으로 4개 모델 35.7초 → 21.3초. 알파 판정 기준 상향(`ALPHA_MIN_RATIO=0.01`)으로 뒤 메시가 앞에 그려지던 문제 수정.
- **번역 엔진** (`src/translation.js`, `src/claude-cli.js`, `src/codex-cli.js`): ChatGPT(Codex CLI) 엔진 추가, Claude 전 모델 선택, 모델이 많으면 하위 메뉴(`buildEngineMenu`). 계정 미연결 시 연결 팝업. 묶음 16개 × 병렬 3으로 96개 제목 21.2초 → 8.8초. "번역 사용 안 함"은 번역 메뉴 항목.
- **모델 디스플레이** (`src/viewer.js`, `src/viewer-preload.js`): 버튼(업로더 페이지·게시물 열기·다운로드·닫기)을 뷰어 화면 안에 겹쳐 표시. 내장 탐색기에서 모델 링크를 누르면 게시물 대신 뷰어를 띄움(`browser.js` `onModel` → `main.js` `previewFromBrowser`, 설정 `browserPreview`).
- **내장 탐색기 메뉴**: 한 줄, 목록·뒤로·앞으로·홈·새로고침은 아이콘 버튼.
- **로그인**: 로그인 버튼 첫 반응 개선, 계정 확인 버튼 제거, 로그아웃은 로그인 상태에서만 표시.
- **테마**: Dark 재설계, Aero 아이콘 개선.
- **배포 용량** (`scripts/release.ps1`, `src/updater.js`): 한국어·영어 외 Chromium 언어 팩 제거, 7z 자산 추가(반디집 `bz.exe`). 업데이트는 7z 우선, 실패 시 ZIP.

## 검증한 것
- 자동 테스트: 92개 통과 (`ELECTRON_RUN_AS_NODE=1 ./vendor/electron/electron.exe --test test/*.test.js`)
- 스모크 테스트 통과(언어 팩 정리 상태), 7z를 Windows `tar`로 풀어 빌드와 파일 대조.
- 실제 사이트(로그인 없이): 내장 탐색기 카드 클릭 → 뷰어, 닫기·업로더 페이지·게시물 열기 버튼.
- 미리보기 도구(`tools/preview`)로 세 테마 화면 확인.

## 확인하지 못한 것
- 7z 자산으로 실제 자동 업데이트(다운로드 → 교체 → 재시작) 전 과정, Windows 10에서의 ZIP 대체 경로.
- 새 MaxScript로 실제 3ds Max 임포트 전체 흐름(배치 실행으로만 확인).
- 로그인 상태의 실제 다운로드, 뷰어의 다운로드 버튼.
- 일부 모델에서 모델 디스플레이가 계속 로딩되는 현상(원인 미확인).

## 알려진 문제·주의
- 릴리스에는 `.7z`와 `.zip`을 모두 올려야 한다. 2.0.0 이하는 ZIP만 찾는다.
- `release.ps1`의 7z 단계는 반디집이 있어야 한다.

## 다음 작업 후보
- `dxcompiler.dll`(26MB) 제거 가능 여부 확인(모델 디스플레이가 WebGPU를 쓰지 않는지).
- 모델 디스플레이 무한 로딩 원인 조사.

## 릴리스 노트
- 화면 위쪽을 압축해 목록이 더 넓게 보입니다. 북마크 버튼은 드래그로 순서를 바꿀 수 있습니다.
- 내장 탐색기에서 모델을 누르면 3D 미리보기가 바로 뜹니다. 미리보기에서 업로더 페이지로 이동할 수 있습니다.
- 번역 엔진에 ChatGPT를 추가했고, AI 번역 속도가 2배 이상 빨라졌습니다.
- 3ds Max 임포트: 임포트 옵션 설정, 임포트 완료 탭, 변환 속도 약 40% 개선.
- 동시 다운로드 기본 6개, 조건 확인과 다운로드를 동시에 진행합니다.
- Dark 테마를 새로 디자인했습니다.
- 배포 파일 용량을 약 34% 줄였습니다(159MB → 105MB).
