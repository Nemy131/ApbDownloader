# v2.1.4 인수인계

작성일 2026-11-23 · 이전 버전 v2.1.3

## 이번 버전 변경 사항

- `src/main.js`와 다운로드 설정 화면에서 무제한 옵션을 제거했다. 새 설정의 기본값은 1개이며 기존 1~64개 설정은 유지한다. 저장된 값이나 계정 설정을 통해서도 64개 상한을 넘길 수 없게 했다.
- `src/core.js`와 `src/site.js`에서 게시물 시작 간격과 자동 계정 행동 간격을 적용한다. 새 계정 설정에서는 자동 팔로우·좋아요·즐겨찾기가 모두 꺼져 있다.
- `src/user-agent.js`에서 Aplaybox 요청과 GitHub 업데이트 요청에 사용하는 문자열을 관리한다. GitHub 최신 릴리스 조회, 7z 및 ZIP 다운로드에 모두 적용한다.

## 검증한 것

- 자동 테스트 100개 통과. 업데이트 메타데이터 조회, 파일 다운로드, 리디렉션 후 최종 요청에서 로컬 HTTP 서버가 받은 User-Agent를 확인했다.

## 확인하지 못한 것

- 로그인 상태에서의 실제 파일 다운로드와 이전 버전에서의 자동 업데이트 설치는 수동 검증 대상으로 남아 있다.

## 다음 작업 후보

- 별도 포터블 설치에서 이전 버전의 자동 업데이트와 재시작까지 확인한다.

## 릴리스 노트

- 사이트 이용 규약 위반으로 동시 다운로드 기능을 제한했습니다. 무제한 옵션을 제거하고 기본값을 1개로 변경했습니다. 기존에 설정한 1~64개 값은 유지됩니다.
- 첫 게시물 이후에는 다음 게시물을 시작하기 전 5~15초 대기합니다. 자동 팔로우·좋아요·즐겨찾기 요청 사이에는 최소 1초 간격을 둡니다.
- Aplaybox 요청과 GitHub 업데이트 확인·다운로드 요청에 같은 User-Agent를 사용합니다.
