# v2.1.1 인수인계

작성일: 2026-11-16 · 이전 버전: v2.1.0

## 이번 버전 변경 사항
- **인증과 다운로드를 한 절차로** (`src/main.js`의 `start()`): 게시물 하나의 조건·첨부 확인(`resolveWork`)이 끝나면 같은 자리에서 그 게시물의 파일을 바로 받는다. 동시에 처리하는 게시물 수는 `concurrency`(또는 `concurrencyUnlimited`) 하나뿐이다. 사이트 확인 요청은 내부적으로 동시에 10개까지(`checkSlot`).
- **설정 정리** (`src/ui/index.html`, `src/ui/ui.js`): "동시 확인" 항목과 `checkConcurrency` 설정 제거. 기존 `settings.json`에 남은 값은 읽을 때 지운다.
- **빌드** (`Build.ps1`, `.gitignore`): 소스 폴더에서 Max 스크립트를 실행하면 생기는 `src/max/ImportMMD.ini`(PC별 설정)를 빌드와 저장소에서 제외.

## 검증한 것
- 자동 테스트: 92개 통과 (`ELECTRON_RUN_AS_NODE=1 ./vendor/electron/electron.exe --test test/*.test.js`)
- 릴리스 스크립트의 스모크 테스트와 7z 대조.

## 확인하지 못한 것
- 로그인 상태의 실제 다운로드로 새 절차(인증 → 다운로드 연속 진행, 무제한 모드) 확인.
- v2.1.0 인수인계의 "확인하지 못한 것" 항목은 그대로 남아 있다.

## 알려진 문제·주의
- 한 게시물에 첨부가 여러 개면 그 파일들은 순서대로 받는다(이전에는 서로 다른 자리에서 동시에 받을 수 있었다).
- 릴리스에는 `.7z`와 `.zip`을 모두 올려야 한다. 2.0.0 이하는 ZIP만 찾는다.
