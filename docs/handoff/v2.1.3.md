# v2.1.3 인수인계

작성일: 2026-11-18 · 이전 버전: v2.1.2

## 이번 버전 변경 사항
- **첫 실행 안내** (`src/ui/ui.js`의 `firstRun`): 사용 방법 창을 한 번 자동으로 띄운다(`localStorage`의 `helpSeen`). 불러온 업로더가 없으면 엔드필드 북마크(`FIRST_AUTHOR`)를 연다.
- **다운로드 전 확인 팝업** (`src/ui/ui.js`의 `downloadReady`·`saveConsent`): 로그인하지 않았으면 로그인 버튼이 있는 팝업, 자동 처리 설정을 저장하지 않았으면 설정 저장 버튼이 있는 팝업을 띄운다. 저장하면 이어서 다운로드한다.
- **로그인 창 자동 닫기** (`src/site.js`의 `closeLoginIfDone`, `src/main.js`의 쿠키 변경 처리): 로그인 창을 연 뒤 새 토큰 쿠키가 생기면 창을 닫고 메인 창으로 돌아온다.
- **카드** (`src/ui/ui.js`, `src/ui/readability.css`): 받지 않은 자료에 "다운로드 후 3ds Max로 임포트" 버튼(`downloadAndImport`, 다운로드가 끝나면 임포트 창을 연다). 게시물 열기 버튼 제거.
- **내장 탐색기** (`src/ui/index.html`): 목록으로 나가는 버튼은 집 아이콘, Aplaybox 첫 화면 버튼은 지구본 아이콘.

## 검증한 것
- 자동 테스트: 94개 통과 (`ELECTRON_RUN_AS_NODE=1 ./vendor/electron/electron.exe --test test/*.test.js`)
- 미리보기 도구(`tools/preview`)로 로그인 팝업, 설정 저장 팝업, 카드 버튼 배치, 내장 탐색기 버튼 줄 확인.
- 릴리스 스크립트의 스모크 테스트와 7z 대조.

## 확인하지 못한 것
- 실제 로그인 후 로그인 창이 닫히는지.
- 새 데이터 폴더로 처음 실행했을 때 엔드필드 목록이 열리는지.
- 다운로드 완료 후 임포트 창이 이어서 열리는지.
- v2.1.0~v2.1.2 인수인계의 "확인하지 못한 것" 항목.

## 알려진 문제·주의
- 내장 탐색기의 다운로드 버튼은 새 팝업을 쓰지 않고 기존 오류 문구를 그대로 보여 준다.
- 릴리스에는 `.7z`와 `.zip`을 모두 올려야 한다. 2.0.0 이하는 ZIP만 찾는다.

## 다음 작업 후보
- `dxcompiler.dll`(26MB) 제거 가능 여부 확인.
- 모델 디스플레이 무한 로딩 원인 조사.

## 릴리스 노트
- 처음 실행하면 사용 방법이 자동으로 표시되고, 엔드필드 북마크가 선택된 상태로 시작합니다.
- 로그인이나 자동 처리 설정 저장이 필요하면 다운로드를 누를 때 안내 창에서 바로 처리할 수 있습니다.
- 로그인이 끝나면 로그인 창이 자동으로 닫힙니다.
- 카드에 "다운로드 후 3ds Max로 임포트" 버튼을 추가했습니다.
