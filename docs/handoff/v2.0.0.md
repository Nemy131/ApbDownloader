## 이번 버전 변경 사항
- **3ds Max로 임포트** (`src/maxbridge.js`, `src/max/`, `src/main.js`의 `maxImport`·`maxConfig`)
  - 내장 PMX 임포터(ImportMMD.ms + pmx_to_fbx.py, 원본: 별도 PMX_Converter 작업물)를 앱에 포함.
  - 선택 도구줄 "3ds Max로 임포트", 다운로드된 카드의 "Max로 임포트".
  - 연동된 Max 1개 → 바로 전송, 여러 개 → 대상 선택 창(버전·씬·PID), 없음 → Max 실행 후 임포트.
  - 연동 스크립트 `ApbMaxBridge.ms`를 사용자 동의 후 Max startup 폴더에 설치.
  - 다운로더에서 보낸 임포트는 결과 팝업 대신 임포트 창 로그에 표시(다음 요청이 막히지 않도록).
  - "3ds Max 임포트 설정" 창: 3ds Max·Blender·반디집 경로, 연동 스크립트 설치/제거, 설정·로그 폴더.
- **번역 캐시 저장** (`src/translation.js`, `src/main.js`, `src/browser.js`, `src/page-translation.js`, `src/ui/ui.js`)
  - `data/translations.json`(최대 2만 개)에 저장, 시작 시 목록에 바로 적용. 내장 탐색기는 캐시된 문장을 한 번에 적용하고 새 문장만 12개씩 번역.
- **번역 엔진 선택** (`src/translation.js`, `src/claude-cli.js`, `src/glossary.js`, `src/main.js`의 `translationEngine`, "번역 설정" 창)
  - Google(기본) / Claude(Claude Code CLI, Haiku·Sonnet). 제목을 최대 40개씩 묶어 한 번에 번역, 실패 시 Google 대체, 게임 용어집(기본 + `data/glossary.txt`).
  - 연결 시험, 용어집 열기, 저장된 번역 지우기.
  - 목록 번역 요청 12개 → 40개, 내장 탐색기는 새 문장을 동시에 요청(Claude일 때 40개).
- **작가 바로가기 통합** (`src/ui/ui.js`의 `renderAuthorShortcuts`·`openAuthorDialog`, `index.html`의 `#authorDialog`): 접히는 "작가 목록 · 북마크" 칸을 없애고 위쪽 바로가기 줄에 북마크(★)·삭제 ✕·우클릭 편집 창·"＋ 현재 작가 북마크"·8개 초과 시 더보기를 넣음. IPC는 기존 `authorBookmark`·`authorRemove` 그대로.
- **카드 다운로드 버튼**: 카드 동작을 아이콘 버튼으로 변경(`iconButton`, `ICONS`: 북마크·게시물 열기·Max 임포트, 오른쪽 끝 다운로드). 다운로드 아이콘은 그 자료만 다운로드(`downloadOne`: 선택 후 `start`에 id 하나, 기록·폴더 제외 없이).
- **썸네일 호버 재생**: 썸네일 호버 시 블러 + 재생 버튼 → `openPost(id, true)` → `site.open(w,{play:true})`가 게시물 창을 열고 `playModel()`로 모델 디스플레이 iframe(`details.aplaybox.com/modelDetails`)의 재생 아이콘 `.icon-ziyuan`을 클릭(최대 20초 대기). 사이트 구조가 바뀌면 `src/site.js`의 `PLAY_SCRIPT`·`CLICK_SCRIPT` 수정.
- **설정 창으로 정리**: 상단의 "다운로드 설정" 접이식 패널을 없애고 헤더 로그아웃 옆 ⚙ 아이콘(`#settingsBtn`) → 설정 창(`#settingsDialog`: 자동 처리·동시 다운로드·완료 알림·번역·3ds Max)으로 이동. 작가 페이지 패널은 전체 폭. 요소 id는 그대로라 기존 핸들러 유지.
- **메인 화면 모델 디스플레이 뷰어** (`src/viewer.js`, `src/main.js`의 `viewerOpen`·`viewerBounds`·`viewerClose`, `index.html`의 `#viewerOverlay`): 썸네일 재생 버튼이 게시물 창 대신 `details.aplaybox.com/modelDetails?work_uuid=<id>&work_type=<1|2>&isLogin=0&Api_url=1`을 WebContentsView로 직접 불러와 `#viewerStage` 위치에 겹쳐 표시. 로드 후 `.icon-ziyuan` 클릭, 이후 본문 `%`로 진행률 전달, `section.p_three_canvas`가 모두 숨겨지면 완료. 이동은 details.aplaybox.com만 허용, 새 창 거부. 닫으면 about:blank로 비워 렌더링 중지. 모서리는 `view.setBorderRadius(14)`(무대와 동일). 내장 탐색기를 열면 뷰어를 닫음. 기존 `openPost(id,true)` 경로는 뷰어의 "게시물 열기"에서 사용.
- **앱 UI 확인창·툴팁** (`src/ui/popups.js`): `confirm()` 대신 `appConfirm(message,{title,ok,cancel,danger})`(Promise<boolean>). `title` 속성은 `data-tip`으로 옮겨 `.app-tooltip`으로 표시(350ms 지연, 대화상자 안에서도 표시).
- **화면 정리**: 작가 페이지 패널(`#sourcePanel`) 제거 → `#url`은 숨김 입력으로 유지, 조회 범위·새로고침은 목록 제목 줄로, 저장 폴더는 설정 창으로, 내장 탐색기는 바로가기 줄 끝 "Aplaybox 탐색"(`#browse`). 우하단 독 버튼 아이콘화. 자동 번역 옆 `#trQuick`(엔진·모델 빠른 선택). 카드의 "모델 · 작가ID"·조건 배지·기본 안내 문구, 드래그 안내 문구 제거.
- **썸네일 보기** (`ui.js`의 `DENSITY`·`markDensity`·`resizeThumbnails`·`columnsFor`): 크게 3열/340px, 보통 4열/260px, 작게 6열/180px 아이콘 + … 팝오버의 크기 슬라이더(160~480px). 슬라이더는 열 수도 함께 정함(`round(1060/높이)`, 2~6열). 열 수 선택(`#columnCount`)은 제거. 세로 길이 슬라이더(`#thumbnailRatio`, 50~160%, 저장 키 `thumbnailRatio`) → `--thumbnail-height`(= 크기 × 비율, 카드 표지 높이). 저장 키 `thumbnailPx`·`listColumns`(이전 `thumbnailSizeIndex`는 첫 실행 때 변환, 없으면 260).
- **번역 결과 엔진·모델별 저장** (`src/translation.js`): 캐시를 `buckets`(`google`, `claude:haiku`, `claude:sonnet`, 이전 형식은 `legacy`)로 분리. `translations.json` 형식 `{version:2,buckets:{...}}`. `lookup()`은 현재 엔진 우선, `fresh=false`면 다른 엔진 결과도 재사용, `fresh=true`면 현재 엔진 결과만(없으면 새로 번역). Claude 실패로 Google에 넘긴 결과는 `google`에 저장. `view()`가 렌더러용 병합 결과(`translationCache`).
- **엔진 변경 확인** (`ui.js`의 `switchEngine`, `main.js` `translationEngine("switch",{engine,model,fresh})`, 설정 `translateFresh`): 빠른 선택·번역 설정 창 어디서 바꿔도 앱 확인창(새로 번역 / 기존 번역 유지, Esc·바깥 클릭은 변경 취소). Claude 선택 시 본인 계정 사용량 경고(`appConfirm`의 `note`). 변경 후 렌더러 번역 표시를 다시 불러오고, 내장 탐색기 페이지는 원문 복원 후 다시 번역.
- **북마크 작가 새 모델 알림** (`src/author-updates.js`, `main.js`의 `checkBookmarkUpdates`·`markSeen`, 스냅샷 `authorNew`, 데이터 `author-updates.json`): 앱 시작 1.5초 후 1회, 북마크 작가마다 모델 목록 1페이지(20개)부터 읽어 모르는 게시물(저장 목록 + seen 기록에 없음)을 모음. 한 페이지에 아는 게시물이 있으면 중단(최대 5페이지). 처음 확인하는 작가는 1페이지를 기준(seen)으로만 저장. 새 모델은 저장된 목록(`author-lists.json`의 `uid|model` 또는 `uid|all`) 앞에 `isNew:true`로 추가, 현재 표시 중인 작가면 화면 목록에도 추가. 작가를 열면(`load`) newIds를 비우고(북마크 NEW 해제) 카드 `isNew`는 다음 실행 확인 때 정리. 렌더러: 북마크 칩 `.new-badge`, 카드 `.card-new`. 사이트 목록이 최신순이라는 전제.
- **Claude 계정 표시·로그아웃** (`claude-cli.js`의 `authStatus`·`logout` = `claude auth status --json` / `claude auth logout`, IPC `claudeAccount`, 설정 창 번역 항목 `#claudeAccount`·`#claudeLogout`): 설정 창을 열 때 로그인 계정(이메일·플랜) 표시, 로그아웃은 확인창 후 실행. 로그아웃은 Claude 데스크탑 앱 Code 탭과 같은 로그인을 해제하므로 개발 중 실제 실행 시험은 하지 않음(상태 조회만 확인).
- **툴바 통합 2차**: "배포 자료" 제목·개수 제거(`#count`는 숨김 요소로 유지), 선택 도구(`.selection`, 요약 `#summary` 포함)를 툴바 안으로 이동, `#listTools`·`#toggleTools`(목록 도구 접기) 제거.
- **뷰어 툴팁**: 아래쪽이 모델 화면(WebContentsView)에 가려지므로 `.viewer-bar[data-tip-side=left]`로 버튼 왼쪽에 표시(`popups.js`).
- **목록 툴바(`.library>.toolbar`) 최종 구성**: 필터(`#filterDetails`, 체크 목록은 아래 펼침 창, 바깥 클릭 시 닫힘)·검색·정렬(`.list-search`)·썸네일 보기(`.thumbnail-controls`: 3단계 아이콘 + `…` 팝오버)·새로고침 / 둘째 줄 선택 도구(`.selection`)·요약(`#summary`). 위 "툴바 통합 2차"로 제목·조회 범위·`#listTools`는 모두 없어짐.
- **독 버튼 조건부 표시** (`activity.js`의 `renderActivity`): `dockStart`는 작업 중이 아니고 선택이 있을 때, `dockRetry`는 실패·인증 필요가 있을 때, `dockCancel`(붉은 X)은 작업 중일 때만. 모두 숨으면 줄도 숨김. 작업이 없으면(`tone==="idle"`) 독에 `.idle`(상태 줄 숨김), 버튼도 없으면 `.empty`(독 전체 숨김, `updateBackToTop`에서 판정).
- **조회 범위 제거, 모델만 조회**: `main.js`의 `load()`가 `scope`를 항상 `'model'`로 고정(작가 선택 경로도 `'model'`). 렌더러의 `#scope`는 숨김 입력(값 model)으로 남겨 기존 호출 유지. 전체 목록 탭(`tabWorks`)은 이전 실행에서 남은 모션(type 2)을 제외, 북마크 탭은 그대로. 이전에 저장한 `|all` 목록 캐시는 `cachedList`가 모델만 걸러 재사용. 테스트 `lazy-conditions` 범위를 model로 수정.
- 필터에서 팔로우·좋아요·즐겨찾기 조건 항목 제거(조건 자동 처리는 설정 창에 그대로).
- 도움말 버튼은 처음 실행 시 `.attention` 강조(localStorage `helpSeen`이 없을 때), 한 번 열면 해제.
- **압축 파일 이름 번역 옵션** (설정 `translateFileNames`, IPC `fileNameTranslation`, `translation.js` `translatedFileName`·`Translator.cached`, `core.download` `rename`): 저장된 번역·용어집만 사용하고 새 번역 요청은 하지 않음. 기록 없는 이름 변경 파일은 이름 기준 폴더 확인에서 빠짐.
- **테마 색 타이틀 바** (`main.js` `titleBarStyle:'hidden'`·`titleBarOverlay`, IPC `titleBar`, `theme.js` `TITLE`·`syncTitleBar`, `.app-titlebar`, `--titlebar-h`=34px): Windows 기본 제목 표시줄 대신 테마 색 막대(드래그 영역)와 Windows 창 조절 버튼 오버레이. 버튼 색은 테마 CSS가 늦게 적용돼도 맞도록 `theme.js`에 직접 지정(테마 CSS의 `--titlebar-bg/--titlebar-fg`와 같게 유지). 내장 탐색기 패널·뷰어·업데이트 패널을 막대 높이만큼 내림(`browser.js` y=150).
- **Dark 테마 회색조**: 검정 바탕(#000)을 어두운 회색(배경 #18181a, 타일 #242427, 경계 #35353a)으로 올리고 보조 글자색도 약간 밝힘.
- **아일랜드 그림자**: Bento 테마에서 헤더·작가 칩·탭·목록 툴바·설정 타일·푸터에 카드와 같은 `--card-shadow` 적용(Aero는 원래 전체 적용, Dark는 그림자 없음 유지).
- **도움말**: 바로가기 줄 "Aplaybox 탐색" 왼쪽 ? 버튼(`.help-btn`) → `#helpDialog`(작가 불러오기·북마크·선택과 다운로드·3D 미리보기·목록 보기·번역·설정).
- 썸네일을 모든 테마에서 꽉 채우기(`object-fit:cover`)로 통일.
- 목록이 비었을 때 기본 작가 버튼 강조(v1.2.1), "더 찾아보기 →" 버튼(v1.2.2), 업데이트 로그 별도 창(v1.2.2).
