# v2.1.5 인수인계

작성일: 2026-11-27 · 이전 버전: v2.1.4

## 이번 버전 변경 사항
- 기본 북마크에 젠존제(绝区零 공식 계정 `352588796`)와 퍼니싱(战双帕弥什 공식 계정 `870811726`)을 추가했다(`src/default-authors.js`). 두 계정의 공개 게시물 목록(모델 77개·196개, 2026-11-27 기준)을 `src/builtin/author-lists.json`에, 제목 번역 273개를 `src/builtin/translations.json`에 넣었다. 용어집에 `战双帕弥什=퍼니싱: 그레이 레이븐`을 추가했다(`src/glossary.js`).
- 자동 업데이트를 GitHub 릴리스 대신 회사 NAS 공유 폴더(`package.json`의 `updateSource`, UNC 경로)에서 확인하도록 바꿨다(`src/updater.js`). `latest.json`을 읽고 `v<버전>\`의 7z(실패 시 ZIP)를 임시 폴더로 복사하면서 크기·SHA-256을 확인한다. 압축 해제·교체·재시작은 기존과 같다.
- 시작 시 공유 폴더, `latest.json`, 버전 폴더나 파일 중 하나라도 찾지 못하면 아무 창도 띄우지 않는다(`readManifest` 10초, `reachableFiles`로 파일 존재·크기 확인).
- `scripts/release.ps1 -Publish`는 GitHub 릴리스 대신 두 압축 파일을 공유 폴더에 복사하고 복사본 SHA-256을 대조한 뒤 `latest.json`을 마지막에 교체한다. git 태그는 로컬에만 만든다.

## 검증한 것
- 자동 테스트: 104개 중 103개 통과(Linux의 Node 22로 실행). 실패한 1개(`elevated removal script …`)는 PowerShell이 필요한 Windows 전용 테스트로 v2.1.4에서도 같은 환경에서 실패한다.

## 확인하지 못한 것
- Windows에서의 빌드, `release.ps1 -Publish`의 실제 NAS 게시(이 스크립트는 실행해 보지 못했다).
- 실제 UNC 경로에서의 업데이트 확인·복사·교체·재시작.
- 젠존제 신규 캐릭터와 퍼니싱 기체·의상 이름 번역 일부는 공식 한국어 표기가 아닌 음역·독음·의역이다.

## 알려진 문제·주의
- v2.1.4 이하(GitHub에서 업데이트하는 빌드)는 NAS를 모른다. 이 버전은 GitHub 릴리스로 한 번 배포하거나 직접 설치해야 이후 NAS로 업데이트된다.
- 게시하는 PC는 공유 폴더에 쓰기 권한이 있어야 한다.

## 다음 작업 후보
