# v2.1.2 인수인계

작성일: 2026-11-16 · 이전 버전: v2.1.1 (전체 맥락은 `docs/handoff/v2.0.0.md` → `v2.1.0.md` → `v2.1.1.md` 순서)

## 이번 버전 변경 사항
- **ImportMMD 재설치** (설정 ⚙ → 3ds Max 임포트 설정 → ImportMMD 행의 `#maxReinstall` "재설치" 버튼)
  - `src/maxbridge.js` `relatedFiles({userRoot,installDirs})`: 찾는 범위
    - 사용자 폴더 `%LOCALAPPDATA%\Autodesk\3dsMax\<버전>\<언어>\`의 `scripts`(하위 6단계)·`usermacros`(3단계)·`temp`(바로 아래)
    - 설치 폴더(`findMaxExes()` 결과와 설정된 maxExe 폴더)의 `scripts`(6)·`MacroScripts`(3)·`stdplugs\stdscripts`(3)
    - 판정: 이름 `ImportMMD*.(ms|mse|mcr|ini|txt|py)`, `pmx_to_fbx*.py`, `ApbMaxBridge.ms`, 또는 2MB 미만 `.ms/.mse/.mcr` 내용에 "importmmd"(대소문자 무시)
  - `reinstall(files, dirs)`: unlink(ENOENT는 삭제로 간주) → `{removed, failed:[{file,perm,error}], installed:install(dirs)}`
  - `src/main.js` IPC `maxReinstall`: `'scan'` = `{files, startup}`, `'run'` = 삭제 + 연동 스크립트 재설치 + configView. startup 폴더가 없으면 오류(Max를 한 번 실행하라는 안내).
  - `src/ui/ui.js`: scan → 확인창(경로는 `...\Autodesk\(3dsMax\)` 앞부분을 줄여 최대 12개) → run → 결과 토스트. 사용자 설정 폴더 `%LOCALAPPDATA%\ApbDownloader\max-bridge`(ImportMMD.ini·로그)는 건드리지 않음.
- **관리자 권한 삭제**: run 뒤 권한 부족(EPERM/EACCES, `perm:true`)으로 남은 파일이 있으면 "관리자 권한 필요" 확인창 → [관리자 권한으로 삭제] → IPC `maxReinstall('elevate')`
  - main이 `relatedFiles()`로 다시 찾은 목록 중 아직 존재하는 파일만 넘김(렌더러는 경로를 지정하지 않음).
  - `elevatedRemove(files,{runner})`: 임시 폴더 `apb-elevate-*`에 `remove.ps1`(BOM)·`list.txt`(BOM)를 쓰고, `runElevated`가 `Start-Process -Verb RunAs -WindowStyle Hidden -Wait -PassThru`로 관리자 PowerShell 실행 → `result.txt`의 `OK\t경로` / `ERR\t경로\t메시지` 줄을 읽음. UAC 취소는 catch에서 종료 코드 1223 → `canceled:true`. 끝나면 임시 폴더 삭제.
  - 인자는 작은따옴표 인용(작은따옴표는 두 번), 경로 전달은 파일로 해서 한글·공백 경로 문제를 피함.
- `src/preload.js` 허용 목록에 `maxReinstall` 추가. AGENTS.md·README.md에 설명 추가.

## 검증한 것
- 자동 테스트: 94개 통과(v2.1.1의 92개 + 이번 2개) (`ELECTRON_RUN_AS_NODE=1 ./vendor/electron/electron.exe --test test/*.test.js`)
  - 임시 폴더 구조에서 relatedFiles 찾기·깊이 제한·제외 파일 유지, reinstall 삭제 후 연동 스크립트가 내장본과 같은지
  - elevatedRemove: `-Verb RunAs`만 뺀 일반 권한 runner로 한글 폴더·작은따옴표 폴더 파일 삭제, 없는 파일은 OK, 목록 밖 파일 유지, runner가 1223을 돌려주면 canceled·파일 유지
- 실제 PC에서 scan: 관련 파일 4개를 약 0.4초에 찾음. 확인창 화면 확인 후 취소(파일 그대로).
- 2.1.2 빌드(release.ps1): 결과는 릴리스 후 아래에 기록.

## 확인하지 못한 것
- 실제 `run`(사용자 Max 폴더를 바꾸므로 개발 중 실행하지 않음)과 실제 UAC 창·관리자 실행 결과.
- Program Files 아래 파일이 실제로 남는 경우의 "관리자 권한 필요" 확인창 화면.
- v2.1.1 이하 문서의 "확인하지 못한 것" 항목은 그대로 남아 있음.

## 알려진 문제·주의
- 실행 중인 3ds Max는 재설치 후 다시 시작해야 적용됨. Max가 파일을 잠그고 있으면 삭제 실패로 표시될 수 있음(관리자 권한으로도 실패 → 토스트에 사유).
- 내용 검사로 찾기 때문에, 사용자가 만든 다른 스크립트라도 본문에 "ImportMMD"가 있으면 대상이 됨(확인창에 목록이 나오므로 그때 취소 가능).
- 개발 중에는 `maxReinstall('run'|'elevate')`를 실제 앱에서 누르지 말 것(scan과 단위 테스트로 확인).

- 이 변경은 v2.0.0 기준으로 만든 뒤 v2.1.1 위로 옮겼다(rebase). 충돌은 `maxbridge.js` exports, `preload.js` 허용 목록, `index.html`·README 한 줄뿐이었고 원격 쪽 내용을 유지한 채 이번 항목만 추가했다.
